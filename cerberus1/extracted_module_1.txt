1. Module Responsibility

Module 1 owns the data and intelligence pipeline. Its job is to turn FIRs/reports into trusted, traceable structured data and expose that data to Module 2.

Create/select case.

Upload FIR/report.

Store original file and SHA-256 hash.

Extract text directly or through OCR.

Split text into page/chunk evidence.

Run structured entity/event extraction.

Validate the extraction schema.

Return candidates for investigator review.

Normalize approved entities.

Generate entity-match candidates.

Persist confirmed entities/relationships.

Synchronize approved facts to Neo4j.

Expose graph, timeline, patterns and analytics APIs.

6. Entity Resolution

Use exact normalized identifiers first, then conservative candidate scoring. Probabilistic identity matches must remain suggestions until an investigator confirms them.

The supplied concept explicitly describes a possible match such as Rahul Kumar / R. Kumar sharing a phone number and requiring Confirm Match / Reject Match review. fileciteturn0file0L434-L476

Normalize identifiers.

Find exact matches.

Generate fuzzy/name candidates.

Calculate score and reasons.

Store SUGGESTED match.

Expose candidate to Module 2 UI.

Accept/reject decision returns to Module 1.

Only confirmed matches modify trusted relationships.

9. Performance and Reliability

Never load the complete graph by default; support one-hop/controlled expansion.

Use indexes/constraints for normalized identifiers and stable IDs.

Run OCR, extraction and analytics as background jobs.

Make jobs idempotent.

Retry failed jobs without duplicating graph facts.

Return source/evidence references with extracted facts.

Keep raw documents immutable.

10. Module 1 Done Criteria

A sample FIR can be uploaded and processed.

Extracted entities/events are reviewable.

Approved entities are stored in PostgreSQL and Neo4j.

Two cases sharing an identifier become connected.

Graph expansion API returns bounded neighborhoods.

Timeline, pattern and analytics APIs work on synthetic data.

All important facts expose provenance.

Audit logs capture uploads, reviews and match decisions.
