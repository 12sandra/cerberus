4. Investigation Workspace Layout

Use a three-area layout: navigation/sidebar, central graph canvas, contextual right panel. The right panel changes based on the selected case, node, edge, evidence item, pattern, or timeline event.

5. Graph Interaction Contract

Open case → show the case as root.

Render direct relationships as a star topology.

Click a node → request one-hop expansion.

Expand again only when the investigator asks.

Click edge → show relationship type, confidence, evidence and dates.

Click node → show entity profile and linked cases.

Filter by entity type, relationship, date, case and confidence.

Provide Reset to Case.

Set a maximum node count per expansion request.

7. Extraction Review UI

Show original document/page text beside extracted candidates.

Group candidates by entity type.

Each candidate has Approve, Edit and Reject actions.

Display confidence and source page/chunk.

Do not visually imply that an unapproved extraction is a verified fact.

8. Entity Match Review

Show source entity and candidate entity side by side.

Show shared identifiers and similarity reasons.

Display confidence as a suggestion, not a proof.

Buttons: Confirm Match / Reject Match.

After confirmation, refresh graph data.

9. Timeline

Chronological event cards.

Filter by date range, entity and event type.

Selecting an event highlights related graph nodes.

Every event links to evidence.

12. Grounded AI Assistant

Answer only from authorized data returned by Module 1.

Retrieve graph paths/entities for relationship questions.

Retrieve evidence chunks for textual questions.

Show source case/document/evidence references.

If evidence is insufficient, say so instead of inventing an answer.

Provide Show Relationship / Show Evidence actions.

13. AI Query Flow

User asks question.

Classify query.

Call Module 1 graph/entity/timeline APIs.

Call evidence retrieval endpoint or relevant case/evidence APIs.

Build bounded context.

Send context to LLM.

Render answer with evidence references.

Allow investigator to jump to graph/evidence.

16. Module 2 Done Criteria

Investigator can browse cases.

Case graph opens in star topology.

Graph expands one level at a time.

Entity and relationship evidence is visible.

Extraction and match review workflows work.

Timeline and patterns are visible.

Analytics identify high-connectivity entities.

AI assistant answers at least one graph/evidence question with references.

UI handles loading, empty, error and unauthorized states.

Module can run against a mocked Module 1 API and later switch to the real API without code restructuring.
